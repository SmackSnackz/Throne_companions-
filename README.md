# Throne Companions 👑

AI-powered companion chat application with advanced conversation features, tier-based access, and comprehensive admin tools.

## Features

### Core Functionality
- **AI Companions**: Multiple personality-driven AI companions (Sophia, Vanessa, Aurora)
- **Tiered Access**: 4 subscription tiers (Novice, Apprentice, Regent, Sovereign)
- **Advanced Prompting**: Solicitation layer, distress mode anchoring, focused expansion
- **Memory System**: Persistent conversation memory with tier-based retention
- **Persona Selection**: 8 relationship modes (Lover, Wife, Friend, etc.)

### Admin Features
- **Secure Admin Panel**: Email-based authentication with 6-digit access codes
- **Tier Testing**: Test conversation behavior across all subscription tiers
- **Error Monitoring**: Real-time tracking of conversation issues and agent malfunctions
- **Analytics**: Mixpanel integration for user behavior tracking

### Technical Stack
- **Frontend**: React.js with Tailwind CSS
- **Backend**: FastAPI (Python)
- **Database**: MongoDB
- **AI**: Emergent LLM integration (GPT-4o-mini)
- **Authentication**: JWT-based with role management
